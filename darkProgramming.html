Relativistic Boat (2026)

Relativstic Boat is an interactive, graphical simulator that visualizes the relativistic phenomena of time dilation and Lorentz contraction for a moving sailboat (chosen for artistic appeal). The program calculates the relativstically altered time and length intervals for the moving boat given an inputted user velocity, which can be adjusted on a slider or typed in manually. The program's architecture features an object-oriented design, with 5 classes for checkboxes, buttons, clocks, the boat, and the slider. Advanced data types and programming techniques are used, including dictionaries to store class object data, lists to instantiate classes, an event detection loop, time tracking with Pygame's Clock object, string manipulation, etc.

Graphical Calculator (2025)

This project is an object-oriented graphical calculator programmed in Java using the Processing IDE. It features a custom-designed interface with a numeric keypad, operation buttons, and a live display area. All buttons are created using a custom Button class that handles their visuals, hover effects, and click detection. The calculator supports basic operations like addition, subtraction, multiplication, and division, as well as advanced functions such as exponentiation, natural logarithm, square root, factorial, sign toggle, and decimal input. It uses two operands (l and r) with a boolean flag to track which is being edited, while the current value is shown through the dVal display variable. Calculations are handled in the performCalculation() method, which also validates special cases like factorials and logarithms.

Daoist Pharmaceutical (2026)

Daoist Pharmaceutical is a group project in Python, using Pygame, contributed to by myself, Ethan Tang, Simon Sakata, and Kai Yun Chao. This project is an object-oriented tycoon-style game where the player takes the role of the son of the mythological Jade Emperor, sent down to Asia to cure diseases using traditional oriental medicines. The project features random disease spawning and curing, resource spawning and extraction, disease growth, a reputation system that determines victory, incremental difficulty over year timespans, a plethora of purchasable medicines that effect different symptoms, etc. The project utilizes dictionaries, lists, pixel scanning, event detection, complex graphics implementations, etc. I largely contributed to the game UI, Disease class logic, and the Button class.

Musikhelfer (2025)

Musikhelfer is a group project contributed to by myself, Ethan Tang, Simon Sakata, Kai Yun Chao, and Aristotle Stokes. The project is an object-oriented music utility app coded in Java with the Processing IDE, and contains an ear-trainer, tuner, metronome, and auto-harmonizer. I coded the Note class, which allows users to place notes on the score for the auto-harmonizer, as well as the playback functionality and button logic for buttons involved with the auto-harmonizer. This required the use of advanced programming techniques, including array lists, mouse detection and event tracking, screen management via case statements, etc.

ZOOG (2025)

ZOOG is an interactive digital artwork, coded in Java, in the Processing environment. The project uses mouse position detection to draw a set of "ZOOG" sprites following the user's cursor, with dynamic colors that are transformations of the user's mouse position. As such, users are able to draw ZOOG sprites across the screen that shift through the RGB spectrum. This project highlights user interaction, programmical rendering, RGB manipulation, and graphical techniques.

Historic Computer Systems Timeline (2025)

This project is an interactive timeline that shows the evolution of computers over time. Users can hover over nodes on the timeline to view information about specific historic systems, including the Atanasoff-Berry Computer, ENIAC, Atlas, Apple 1, and more. This project was created in Java in the Processing environment, and utilizes layered, programmic drawing of elements in addition to mouse tracking and hitbox strategies.
